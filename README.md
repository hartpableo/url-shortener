# URL Shortener

Conceptually similar to platforms like Bitly. 

Create a shorter/simpler version of a long URL. 

Also has lightweight analytics (visit count).

Built in plain PHP, manually written. For self-study. For fun. :)

## Features

- Shorten a URL
- Redirect short URL to the original URL
- Visit counter (generic and unique)
- API
  - Fetch all URLs
  - Delete short URL (and its stored IP addresses)
- Duplicate short URL prevention
